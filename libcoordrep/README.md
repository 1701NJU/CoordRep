# Historical CoordRep work tree

This directory is retained for provenance of earlier exploratory runs. It is
not the install target for the current JACS revision. Install the current
`CoordRep 1.1.2rc2` package from the repository root; its source is under
`release/jacs-revision-20260806/`.

In particular, files below `revision_results/` may contain retired v1/v2-beta
claims, old Figure 5G/Rosetta outputs, or the superseded periodic values
15,901/172,783/10,957/43.11%. Do not use those files as current manuscript
evidence. The current figure and source-data map is
`../release/jacs-revision-20260806/figures/FIGURE_MAP.md`.
