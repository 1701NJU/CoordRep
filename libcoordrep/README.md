# Historical CoordRep work tree

This directory is retained for provenance of earlier exploratory runs. It is
not the install target for the current JACS revision. Install the current
`CoordRep 1.1.2rc3` package from the repository root using the active frozen
release at `release/jacs-revision-20260826/`.

In particular, files below `revision_results/` may contain retired v1/v2-beta
claims, old Figure 5G/Rosetta outputs, or superseded periodic values.
Do not use those files as current manuscript evidence.

Current manuscript evidence is in `../release/jacs-revision-20260826/`,
and `release/jacs-revision-20260823/` plus `release/jacs-revision-20260819/`
are retained as historical superseded releases.
