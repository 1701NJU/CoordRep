# Figure 1 — cisplatin-centered 3C representation

The current master is `Figure1_Cisplatin_3C_20260822.svg`; the PDF, 600 dpi
PNG/TIF, and 180 dpi preview were exported from that exact SVG on 2026-08-23.
The figure uses the experimental cisplatin first sphere from CUKRAB02 and the
public IUCr source associated with DOI 10.1107/S1600536812024014.

`Figure1_source_values.csv` provides the source hash, corrected coordinate-space
CShM values, and relation counts. `Figure1_manuscript_caption_20260828.txt` is
the exact publication-facing caption; `Figure1_caption_replacement.md` retains
expanded development notes. Raw CIF/CSD coordinates are not redistributed in
this release.
