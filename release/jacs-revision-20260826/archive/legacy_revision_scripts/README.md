# Historical revision scripts

These scripts generated figures, tables, or manuscript drafts from superseded
revision stages, including the former Figure 5 pathway/family analysis and
retired Rosetta, Tool A/Tool B, v2-beta coverage, and scope-waterfall outputs.
They are retained only for Git provenance and are not active manuscript
generators or current full-CSD audit tools.

Current publication-facing code and evidence are identified in the root
`DATA_MANIFEST.md`, the release `README.md`, and `RELEASE_MANIFEST.json`.
