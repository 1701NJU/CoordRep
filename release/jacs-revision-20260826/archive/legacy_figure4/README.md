# Historical Figure 4 artifacts

These files document superseded pre-rc3 Figure 4 analyses and are retained
only for provenance. The earlier relation-field hybrid used rc2 molecular
inputs, whereas the earlier shape-field hybrid used rc1 molecular inputs.
They are not active manuscript evidence and must not be combined or described
as one rc2 benchmark. The publication-facing Figure 4 and its aggregate rc3
validation package are under `figures/Figure4/`.
