# Model evidence boundary

This directory contains public model implementations and compact metric or
dataset-audit outputs used to inspect the reported graph and Cartesian
baselines. Trained checkpoint weights are not part of the public release.

The publication-facing evidence is therefore the split-summary and dataset-
audit metadata, aggregate metrics, source code, and release checksums where
those files are present. A fresh training run requires the
licensed or separately obtained input data described in the Supporting
Information and is not represented as a byte-for-byte checkpoint replay.
