# Figure 3 source package

The CSV files are the public, reproducible source tables for the CN4
SP/Td, CN5 TBPY/SPY, and CN6 octahedral/JT geometry atlases used in the
manuscript. `draft_corrected_figure3_atlas.png` is a convenience preview of
the composite. The final publication artwork is embedded in the submission
manuscript; the tabular sources are authoritative for regeneration and
numerical checking.

No CSD coordinate files are included. The atlas tables contain derived CShM
coordinates and aggregate labels only.
